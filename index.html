☁️ 私有云同步教程

1. 注册 Supabase

访问 supabase.com，点击 "Start your project"。

2. 建表 (最关键一步)

进入 SQL Editor，粘贴下方代码并点击 Run：

create table diary_backup ( id bigint primary key, updated_at timestamp with time zone, diary_data jsonb, todo_data jsonb, settings jsonb, device_info text ); alter table diary_backup enable row level security; create policy "Public Access" on diary_backup for all using (true);

3. 获取 Key

在 Project Settings -> API 中找到 URL 和 Key，填入日记本。
