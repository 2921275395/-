☁️ 云端同步设置教程

第一步：注册 Supabase

1. 访问 supabase.com 并点击 "Start your project"。

2. 注册账号，点击 "New Project"，填写 Name (如 Diary)，设置 Password (要记住)，Region 选 Singapore/Tokyo。

3. 等待项目变成绿色 "Active" 状态。

第二步：创建数据表

1. 在 Supabase 页面左侧菜单点击 SQL Editor 图标。

2. 点击 "New query"，将下方代码复制进去，然后点击右下角 Run。

create table diary_backup ( id bigint primary key, updated_at timestamp with time zone, diary_data jsonb, todo_data jsonb, settings jsonb, device_info text ); alter table diary_backup enable row level security; create policy "Public Access" on diary_backup for all using (true);

第三步：连接日记本

1. 点击 Supabase 左下角齿轮 Project Settings -> API。

2. 找到 Project URL 和 anon public key。

3. 复制这两个值，填入日记本的输入框中，点击保存。
